FreeStorage 

FreeStorage is a personal cloud storage app that uses multiple Google Drive accounts as one storage system.

Instead of switching between different Google accounts, you can connect them to FreeStorage and manage your files from one place.

Features
1. Google login
2. Connect multiple Google Drive accounts
3. Upload photos, videos, and other files
4. Create and manage folders
5. Browse files from one dashboard
6. Image previews
7. Track storage usage
8. Automatically use connected Drive accounts for storage
